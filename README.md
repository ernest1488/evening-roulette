# Рулетка вільного вечора — версія 2

Локальний застосунок українською на HTML, CSS і JavaScript без зовнішніх залежностей, API чи облікових записів. 64 вбудовані заняття, 10 тематичних оформлень і базова тема для інших категорій. Попередні обране та виключення мігрують автоматично.

## Запуск і перевірки

Потрібен Node.js 20+. Встановлювати пакети не потрібно.

```sh
git clone https://github.com/ernest1488/evening-roulette.git
cd evening-roulette
npm run dev
```

Відкрийте http://127.0.0.1:4173. Зупинка сервера — Ctrl+C.

```sh
npm test
npm run build
npm start
```

Збірка перевіряє синтаксис JavaScript і створює статичну папку `dist/`. `npm start` обслуговує її; `npm run dev` — вихідні файли. Не запускайте обидва сервери одночасно: порт 4173 спільний. Сервер прив’язаний до 127.0.0.1 і не публікує застосунок. Для модулів потрібен HTTP, а не відкриття HTML через file://.

## Режими

- **Для мене.** Одна випадкова ідея за часом, бюджетом, компанією, місцем, настроєм і максимальною енергією. Додаткові фільтри згортаються. Є перемикач «Лише мої ідеї».
- **Схоже / Добре поєднується.** Альтернатива замінює основну ідею; доповнення додається лише вручну. Пропозиції враховують виключення й фільтри. Для вбудованих занять використовуються явні зв’язки; для власних — правила сумісності категорій у `logic.js`.
- **Мій вечір.** З’являється після додавання доповнення. Кнопки змінюють порядок усіх пунктів, зокрема основного; доступні сумісна заміна, видалення доповнень і запуск плану. Час та орієнтовна вартість додаються. Перебудова після зміни фільтрів виконується лише за дією користувача.
- **Обираємо разом.** 2–6 учасників на одному пристрої. Добірка до 10 ідей незмінна в межах раунду; голоси попередніх учасників не показуються. Виводяться одностайні збіги або лідери з точним числом голосів. Джерело ідей береться з налаштувань основної рулетки. Перезавантаження починає груповий раунд заново; голоси не зберігаються.
- **Мої ідеї.** Додавання, редагування, пошук, видалення з підтвердженням, окрема рулетка й налаштування включення до загальної. Експорт та імпорт JSON до 2 МБ. Перед імпортом показуються нові, дублікати й некоректні записи; існуючі id не перезаписуються.
- **Обране / Виключені / Історія.** Незалежні списки. Історія містить знімки завершених занять із датою та необов’язковою оцінкою. Видалення власного заняття не знищує старий запис. «Не моє» не означає виключення.
- **Виконання.** Кроки з чекбоксами, потрібні речі, необов’язковий таймер із паузою/продовженням/скиданням. Відлік використовує часові мітки та враховує фоновий час. Ні «Почати», ні завершення таймера не записують виконання. План підтримує пропуски та підсумок; після перезавантаження можна продовжити або скинути прогрес.

## Дані та розширення

- `src/activities.js`, `src/extra-activities.js` — основні дані, включно з трьома початковими кроками вбудованих занять.
- `src/metadata.js` — категорії, настрої, енергія, потрібні речі та явні зв’язки.
- `src/logic.js` — фільтри, підбір, сумісність плану, голосування, таймер і завершення.
- `src/storage.js` — валідація, JSON-імпорт, формат збереження версії 2 і міграція.
- `src/ui.js` — спільні картки, екранування текстів, локальні SVG та фільтри.
- `src/app.js` — режими, форми, діалоги та взаємодії.
- `src/style.css` — адаптивний дизайн і категорійні теми.

Щоб додати вбудоване заняття, додайте рядок до `extraRows` зі стабільним унікальним id, назвою, описом, хвилинами, бюджетом, масивами компанії та місць і кроками. Призначте категорію в `metadata.js`; там же можна додати речі, схожі ідеї та доповнення. Посилання мають вести на наявні id. Для звичайного користувача достатньо форми «Мої ідеї».

Щоб додати тему, зареєструйте категорію в `metadata.js`, додайте SVG-мотив до `motifs` у `ui.js` і клас `.theme-назва` в CSS. Задайте `--card-bg`, `--card-ink`, `--card-muted`, `--card-line`, композицію та оформлення заголовка `.card-copy > h2/h3`. Перевірте повну й компактну картки. Невідома категорія використовує тему `base`.

Формат експорту: `{ "version": 2, "activities": [...] }`; також приймається масив занять. Обов’язкові поля запису: `id`, `title`, `description`, `category`, `duration`, `cost`, `company`, `places`, `moods`, `energy`, `steps`; `things` необов’язкове. Власні записи мають 1–6 кроків. Бюджет задається не більше ніж із двома десятковими знаками.

Основний ключ localStorage — `evening-state-v2`. Старі `evening-favorites` і `evening-excluded` читаються під час першої міграції та не видаляються. Зберігаються власні заняття, історія, фільтри, налаштування, план і активне виконання. Пошкоджені записи відкидаються, а недоступність сховища не блокує роботу в пам’яті. Дані не синхронізуються між браузерами або пристроями.

## Виконана перевірка

- Автоматизовані тести: старі фільтри й пороги, настрій/енергія, явні зв’язки, сумісність та суми плану, заміни, копійки, групова добірка, одностайність/нічия/нуль голосів, імпорт/дублікати/екранування HTML, міграція, збереження прогресу, пошкоджене сховище, унікальні завершення та часові мітки таймера.
- Браузер: створення, помилки форми, редагування, пошук, видалення з підтвердженням; імпорт із 1 новим, 2 дублікатами й 1 некоректним записом. HTML у назві показався текстом. Дані відновилися після перезавантаження.
- Браузер: рулетка власних ідей із одним результатом, нові фільтри й порожній результат; груповий раунд для двох із передачею пристрою та результатом «2 із 2».
- Браузер: додавання доповнення, повідомлення «31 хв — ліміт 30 хв», перебудова зі збереженням основної ідеї, порядок із клавіатури, сумісна заміна, виконання плану та пропуски без запису в історію.
- Браузер: крок і активний таймер після перезавантаження, пауза, подвійне натискання завершення без дубліката, оцінка, підсумок; знімок історії залишився доступним після видалення оригіналу.
- Оглянуто всі 10 тем і базову, повні та компактні картки з довгими назвами. На 360 px ширина документа дорівнює 360 px, переповнення карток немає. Форма діалогу теж не має горизонтального прокручування. Контраст тексту описів до фону тем: від 4,67:1 до 9,85:1.

Тести для нічиєї, нульових голосів, недоступного сховища та довгого фонового відліку виконано на рівні логіки; ці випадки не імітувалися вручну в браузері. Окремого тестування на фізичному телефоні чи зі скринридером не проводилося. Ціни умовні; актуальні години роботи, квитки й погода не перевіряються. «Надворі» охоплює заняття поза домом, зокрема кіно та музей.
